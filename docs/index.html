O cobihw é um widget leve e customizável para Windows que mostra o uso dos recursos de hardware em tempo real, num canto da tela, do jeito que você configurar.

    Funcionalidades

    Tudo o que importa sobre o desempenho do PC, num lugar só, sem precisar abrir o Gerenciador de Tarefas.

    CPU
    Porcentagem de uso e frequência atual do processador.
    GPU
    Porcentagem de uso, memória e, opcionalmente, temperatura. A temperatura depende do suporte do driver.
    RAM
    Porcentagem de uso e memória utilizada em relação ao total.
    Disco
    Tempo ativo e, opcionalmente, velocidades de leitura e escrita. Monitore o disco do Windows ou outro de sua escolha.
    Rede
    Velocidades de download e upload, dados trafegados e ping.
    Bateria
    Monitore o nível de carga, estado de carregamento e tempo restante.
    FPS
    Monitore o FPS em jogos.

    Como instalar

    O cobihw não precisa ser instalado: é uma pasta com o executável. Extraia e abra.

    Requer: Windows 11 ou Windows 10 22H2, 64 bits
    Recomendado

    Portátil

    Vem com tudo o que precisa para rodar. Não exige instalar mais nada no computador.

    Baixar versão portátil (.zip)

    Compacta

    Bem menor, mas exige o .NET Desktop Runtime 10 ou superior instalado.

    Baixar versão compacta (.zip)

    Primeiro uso

    1. Extraia o .zip em uma pasta onde o cobihw vai ficar, como Documentos. As configurações ficam salvas nessa mesma pasta. Fora dela, o cobihw só grava algo se você ligar Iniciar com o Windows ou o FPS, e Configurações → Geral → Remover o cobihw do Windows desfaz os dois.
    2. Abra o cobihw.exe. Se aparecer a tela azul "O Windows protegeu o computador", clique em Mais informações e depois em Executar assim mesmo. Isso acontece porque o programa ainda não possui assinatura digital.
    3. Arraste o widget para onde preferir. O ícone do cobihw fica na área de notificação, ao lado do relógio (se não aparecer, clique na setinha ^). O clique com o botão esquerdo mostra ou esconde o widget; o direito abre o menu para mudar a visualização, abrir as configurações ou sair.
