    Features

    Everything that matters about your PC's performance, in one place, without opening Task Manager.

    CPU
    Usage percentage and current processor clock.
    GPU
    Usage percentage, memory and, optionally, temperature. Temperature depends on driver support.
    RAM
    Usage percentage and used memory out of the total.
    Disk
    Active time and, optionally, read and write speeds. Monitor the Windows disk or another one of your choice.
    Network
    Download and upload speeds, data used and ping.
    Battery
    Charge level, charging state and time left.
    FPS
    FPS in games. The first time, Windows asks for administrator permission.

    How to install

    cobihw doesn't need installing: it's a folder with the executable. Extract it and open it.

    Requires: Windows 11 or Windows 10 22H2 or later, 32 or 64-bit
    Your Windows is:

    Not sure? See Settings → System → About → System type. Windows 11 is always 64-bit.

    Recommended

    Portable

    Comes with everything it needs to run. Nothing else to install on the computer.

    Download portable version (.zip)

    Compact

    Much smaller, but needs the .NET Desktop Runtime 10 or later installed.

    Download compact version (.zip)

    First use

    1. Extract the .zip to a folder where cobihw will stay, such as Documents. The settings are saved in that same folder.
    2. Open cobihw.exe. If the blue "Windows protected your PC" screen appears, click More info and then Run anyway. This happens because the app isn't digitally signed yet.
    3. Drag the widget wherever you like. To set up the widget's features and display, right-click its icon in the notification area and browse the options.
